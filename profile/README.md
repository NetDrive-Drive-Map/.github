## NetDrive Highlights

- **Drive Map:** NetDrive drive map attaches a remote folder to a letter on your computer.
- **Cloud Disk:** NetDrive cloud disk is that letter when the source is cloud storage you may use.
- **Cache Mode:** NetDrive cache mode decides whether files stay only online or a working copy sits locally for a while.
- **SFTP Mount:** NetDrive sftp mount connects a host that expects a protected file session.
- **Reconnect:** NetDrive reconnect brings the same map back after sleep or a short network gap.

---

## What Is NetDrive

NetDrive maps remote storage so it behaves like a disk for everyday files. NetDrive drive map is the connection. NetDrive cloud disk is what you open for a cloud account. A homework folder, a family album, or a small office share can sit on that letter. Use accounts and hosts you are allowed to reach.

NetDrive cache mode matters on a laptop that is not always online. A cache lets you open a recent file more quickly. NetDrive sftp mount is the path for a server that offers SFTP. NetDrive reconnect saves you from rebuilding the map after you close the lid between classes. The goal is a stable letter, not a pile of one-off copies.

Set one NetDrive drive map, choose NetDrive cache mode you understand, and open a single file. If the source is a server, use NetDrive sftp mount. After a restart, confirm NetDrive reconnect restores NetDrive cloud disk before you add a second account.

## Starting with NetDrive

Prerequisites: A compatible computer, a cloud or SFTP account you may use, and permission to run NetDrive.

1. **Prepare:** Note the account before you create NetDrive drive map.
2. **Pick The Disk:** Name NetDrive cloud disk with a letter you will remember.
3. **Choose Cache:** Set NetDrive cache mode for a small working set, not an entire library, on the first day.
4. **Or Use SFTP:** If the source is a server, connect with NetDrive sftp mount.
5. **Open A File:** Edit one document and save it back.
6. **Sleep Test:** Close the lid, wake the computer, and confirm NetDrive reconnect.
